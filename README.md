# Pendhapa Sogan Yogyakarta

Concept website for a fictional Javanese heritage hotel in Yogyakarta. Bilingual (English / Bahasa Indonesia), mobile-first, built with Vite, React, TypeScript and Tailwind CSS.

Photos are illustrative, from Wikimedia Commons under free licences; credits are listed in the site footer.

```bash
npm install
BASE_PATH=/Pendhapa-Sogan-Hotel-Website/ PRELOAD_FONTS=cormorant-garamond-latin-wght-normal,jost-latin npm run build
```
